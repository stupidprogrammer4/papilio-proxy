# آموزش راه‌اندازی پاپیلیو

[English](getting-started.en.md) · [معرفی پروژه](../README.fa.md)

## ۱. آماده‌سازی میزبان

از Linux، macOS با Docker Desktop، یا Windows با WSL2 و اتصال Docker Desktop استفاده کنید.
Bash، Git، Docker همراه Compose، اینترنت برای ساخت image و پورت آزاد لازم است.
ابزارهای ساخت Python و Node داخل image اجرا می‌شوند.

مخزن یا نسخهٔ دلخواه پاپیلیو را دریافت و وارد پوشهٔ اصلی پروژه شوید.
دستورهای زیر از همان پوشه اجرا می‌شوند. شرایط میزبان و ظرفیت‌ها در [راهنمای استقرار](deployment.md) آمده‌اند.

## ۲. نصب آزمایشی محلی

```bash
bash scripts/deploy/install.sh \
  --public-url http://127.0.0.1:8080 \
  --http-port 8080 \
  --owner-username myadmin
```

نصب‌کننده رمز مدیر را خصوصی دریافت می‌کند، برنامه و دیتابیس را آماده می‌کند و پس از بررسی سلامت،
آدرس پنل را نشان می‌دهد. نام مدیر را خودتان انتخاب کنید. مثال HTTP محلی برای دسترسی عمومی نیست.

## ۳. HTTPS عمومی و تلگرام اختیاری

دامنهٔ تحت کنترل خود را به میزبان وصل کنید. پورت ۸۰ برای اعتبارسنجی گواهی و پورت ۴۴۳ برای HTTPS
باید از بیرون قابل دسترس باشند؛ تنظیم مودم، فایروال و مسیریابی بالادستی نیز باید درست باشد.

```bash
bash scripts/deploy/install.sh \
  --project-name my-panel \
  --state-dir "$HOME/papilio-state" \
  --public-url https://panel.example.com \
  --bind-address 0.0.0.0 \
  --http-port 80 --https-port 443 \
  --owner-username myadmin \
  --enable-bot
```

دامنهٔ نمونه را عوض کنید. Caddy صدور و تمدید گواهی را انجام می‌دهد؛ DNS و دسترسی بیرونی باید از قبل
درست باشند. نصب‌کننده توکن تلگرام را خصوصی می‌گیرد. برای خاموش‌بودن بات، `--enable-bot` را حذف کنید.
رمز و توکن را در آرگومان دستور نگذارید و دادهٔ نصب را وارد Git نکنید.

## ۴. تنظیم کسب‌وکار

ابتدا دسترسی مدیران و سیاست تجاری را بررسی کنید؛ سپس مقصد واریز، قیمت، حجم/مدت، باندل کانفیگ
و روش تحویل را تنظیم کنید. تأیید پیامکی به گوشی Android ثبت‌شده، فرستندهٔ دقیق، parser بانک
و سیاست تأیید مشخص نیاز دارد.

نصب هسته، مسیر شبکه، اعمال محدودیت و اتصال از نصب پنل جدا هستند. هسته و کلاینت هدف را پیش از
فروش بررسی کنید. گردش خرید، بازیابی خطا و بازیابی یک پشتیبان رمزگذاری‌شده را برای همین نصب آزمایش کنید.

## ۵. مدیریت نصب

```bash
bash scripts/deploy/status.sh --state-dir "$HOME/papilio-state"
bash scripts/deploy/stop.sh --state-dir "$HOME/papilio-state"
bash scripts/deploy/start.sh --state-dir "$HOME/papilio-state"
```

مسیر state انتخاب‌شده هنگام نصب را استفاده کنید و آن را همراه volume دیتابیس حفظ کنید؛ توقف، آن‌ها
را حذف نمی‌کند. برای ارتقا، سازگاری نسخه و بازیابی از [راهنمای استقرار](deployment.md) پیروی کنید.
بالاآمدن پنل به‌تنهایی اثبات اتصال VPN نیست.
