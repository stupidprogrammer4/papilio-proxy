# آموزش راه‌اندازی پاپیلیو

[English](getting-started.en.md) · [معرفی پروژه](../README.fa.md)

## ۱. آماده‌سازی میزبان

روی سرور Linux دامنه را به سرور وصل کنید و پورت‌های ۸۰ و ۴۴۳ را باز بگذارید.
نصب‌کنندهٔ یک‌خطی کد برنامه را دریافت می‌کند، در توزیع‌های پشتیبانی‌شده در صورت نیاز Docker را نصب می‌کند
و فایل‌های برنامه و state را در مسیر ثابت home نگه می‌دارد. ابزارهای Python و Node داخل image هستند.

## ۲. نصب پنل

```bash
set -o pipefail; curl -fsSL https://raw.githubusercontent.com/stupidprogrammer4/papilio-proxy/main/scripts/deploy/quick-install.sh | bash
```

نصب‌کننده آدرس پنل و نام مدیر (پیش‌فرض `admin`) را می‌پرسد و رمز را خصوصی می‌گیرد؛ imageها و دیتابیس را آماده می‌کند
و پس از بررسی سلامت، آدرس پنل و مسیر state را نشان می‌دهد. دامنه باید به سرور اشاره کند و پورت‌های ۸۰ و ۴۴۳ باز باشند.
برای نصب بدون پرسش، `--public-url` و `--owner-username` را پس از `bash -s --` بدهید. برای آزمایش فقط روی همان سرور، از `--public-url http://127.0.0.1:8080` استفاده کنید.

## ۳. فعال‌کردن بات تلگرام

برای نصب Telegram bot، دستور را با `bash -s -- --enable-bot` تمام کنید. Caddy صدور و تمدید گواهی را انجام می‌دهد؛
DNS و دسترسی بیرونی باید از قبل درست باشند. نصب‌کننده توکن تلگرام را خصوصی می‌گیرد.
رمز و توکن را در آرگومان دستور نگذارید و دادهٔ نصب را وارد Git نکنید.

## ۴. تنظیم کسب‌وکار

ابتدا دسترسی مدیران و سیاست تجاری را بررسی کنید؛ سپس مقصد واریز، قیمت، حجم/مدت، باندل کانفیگ
و روش تحویل را تنظیم کنید. تأیید پیامکی به گوشی Android ثبت‌شده، فرستندهٔ دقیق، parser بانک
و سیاست تأیید مشخص نیاز دارد.

نصب هسته، مسیر شبکه، اعمال محدودیت و اتصال از نصب پنل جدا هستند. هسته و کلاینت هدف را پیش از
فروش بررسی کنید. گردش خرید، بازیابی خطا و بازیابی یک پشتیبان رمزگذاری‌شده را برای همین نصب آزمایش کنید.

## ۵. مدیریت نصب

```bash
bash scripts/deploy/status.sh --state-dir "$HOME/papilio-state"
bash scripts/deploy/stop.sh --state-dir "$HOME/papilio-state"
bash scripts/deploy/start.sh --state-dir "$HOME/papilio-state"
```

مسیر state انتخاب‌شده هنگام نصب را استفاده کنید و آن را همراه volume دیتابیس حفظ کنید؛ توقف، آن‌ها
را حذف نمی‌کند. برای ارتقا، سازگاری نسخه و بازیابی از [راهنمای استقرار](deployment.md) پیروی کنید.
بالاآمدن پنل به‌تنهایی اثبات اتصال VPN نیست.
